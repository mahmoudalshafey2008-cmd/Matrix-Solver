
# Matrix Solver

A linear algebra assignment for the Faculty of Computer and Information Sciences (FCIS), 2026-2027.

## About

Matrix Solver takes a system of linear equations as an augmented matrix, from 1x2 up to 10x11, and solves it step by step. The user chooses Gaussian elimination, Gauss-Jordan elimination, or both.

## Requirements

Requires Python 3.14 or newer

## Input

Enter the number of variables, then each row as space-separated numbers. 
Fractions like 1/2 are accepted.
